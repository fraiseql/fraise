# Pinned install of confiture for the CI gate, where
# `crates/fraise/src/exit_table.rs` diffs the vendored contract
# (`exit_table.vendored.json`) against what this confiture emits.
#
# Confiture owns the only frozen exit taxonomy in the stack, so `fraise` reads every
# tool's exit in its classes rather than inventing a tenth. The vendored file is
# `confiture --exit-codes-json` captured verbatim, with the face's own `mappings`
# section added; the test compares the confiture half whole, and **fails rather than
# skips** when confiture is absent, unanswering or a different release. Measuring it
# against whatever PyPI serves on the day of the run would make the contract a moving
# target, so the release is named here.
#
# Every version is exact, transitive ones included: the verdict is produced by
# third-party code, and an unpinned resolver hands someone else's release day the power
# to redden an untouched tree. Bumping is a deliberate commit that regenerates the
# vendored file in the same breath — the test asserts `confiture --version` reports the
# version pinned here, so a bump without a regeneration fails, and a regeneration
# without a bump fails too. Regenerate this list with:
#
#     uv venv --python 3.11 /tmp/confiture
#     uv pip install --python /tmp/confiture/bin/python fraiseql-confiture==<version>
#     uv pip freeze --python /tmp/confiture/bin/python
#
# Keep the interpreter at 3.11: it is confiture's own floor (`Requires-Python >=3.11`)
# and the interpreter this transitive set was resolved on. fraiseql
# (`tools/confiture-requirements.txt`) and fraisier-core carry the identical list, and
# the three are kept on the same confiture so the stack is measured against one release.
#
# The CLI reference this pin was checked against is confiture's docs/reference/exit-codes.md
# at tag v1.19.0 (github.com/fraiseql/confiture).
